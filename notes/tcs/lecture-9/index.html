TCS: Space Complexity

Space Complexity

Space Can Be Reused

Time counts all executed steps; space counts the maximum amount of working memory used at once. An algorithm can revisit the same memory many times

For sublinear space bounds, use a read-only input tape whose cells are excluded from the workspace count. The work tapes are read/write, and their visited cells determine the space cost

SPACE⁡(s(n))={L:L has a deterministic O(s(n))-space decider}NSPACE⁡(s(n))={L:L has a nondeterministic O(s(n))-space decider}PSPACE=⋃k≥1SPACE⁡(nk)NPSPACE=⋃k≥1NSPACE⁡(nk)\begin{aligned}\operatorname{SPACE}(s(n))&=\{L:L\text{ has a deterministic }O(s(n))\text{-space decider}\}\\\operatorname{NSPACE}(s(n))&=\{L:L\text{ has a nondeterministic }O(s(n))\text{-space decider}\}\\\mathrm{PSPACE}&=\bigcup_{k\ge1}\operatorname{SPACE}(n^k)\\\mathrm{NPSPACE}&=\bigcup_{k\ge1}\operatorname{NSPACE}(n^k)\end{aligned}SPACE(s(n))NSPACE(s(n))PSPACENPSPACE​={L:L has a deterministic O(s(n))-space decider}={L:L has a nondeterministic O(s(n))-space decider}=k≥1⋃​SPACE(nk)=k≥1⋃​NSPACE(nk)​

SAT is in PSPACE: enumerate assignments with a binary counter and evaluate the formula for each assignment, reusing the same workspace. The running time may be exponential while the space remains polynomial

Configuration Graphs

A configuration contains the state, head positions, and work-tape contents. For s(n)≥log⁡ns(n)\ge\log ns(n)≥logn, an O(s(n))O(s(n))O(s(n))-space machine has at most

N=2O(s(n))N=2^{O(s(n))} N=2O(s(n))

possible configurations on a fixed input. This count includes the input-head position, which costs O(log⁡n)O(\log n)O(logn) bits

A deterministic decider cannot repeat a configuration, since a repetition would cause an infinite loop. Hence

SPACE⁡(s(n))⊆TIME⁡(2O(s(n)))\operatorname{SPACE}(s(n)) \subseteq\operatorname{TIME}(2^{O(s(n))}) SPACE(s(n))⊆TIME(2O(s(n)))

A computation of t(n)t(n)t(n) steps can visit only O(t(n))O(t(n))O(t(n)) work cells, so time also gives a space upper bound. Enumerating polynomial-length NP witnesses yields

P⊆NP⊆PSPACE⊆EXP\mathrm P\subseteq\mathrm{NP}\subseteq \mathrm{PSPACE}\subseteq\mathrm{EXP} P⊆NP⊆PSPACE⊆EXP

Deterministic space is closed under complement by exchanging the answers of a decider. Thus coNP⊆PSPACE\mathrm{coNP}\subseteq\mathrm{PSPACE}coNP⊆PSPACE as well

TQBF and PSPACE-Completeness

A fully quantified Boolean formula has no free variables, for example

∀x ∃y: (x↔y)\forall x\ \exists y:\ (x\leftrightarrow y) ∀x ∃y: (x↔y)

This formula is true, since yyy can be chosen after observing xxx. Reversing the quantifiers gives a false formula: one fixed yyy cannot equal both possible values of xxx

TQBF is the language of true fully quantified Boolean formulas

Membership in PSPACE

Evaluate the quantifiers recursively. At an existential quantifier, OR the results for the two assignments; at a universal quantifier, AND them

Depth-first evaluation stores the current partial assignment, the position in the formula, and a recursion stack of polynomial depth. It reuses space between branches, giving a polynomial-space algorithm

A Succinct Reachability Formula

Let a machine use s=poly⁡(n)s=\operatorname{poly}(n)s=poly(n) space. Its configurations have O(s)O(s)O(s) bits and its configuration graph has 2O(s)2^{O(s)}2O(s) vertices

Write Rk(c,d)R_k(c,d)Rk​(c,d) for reachability from ccc to ddd in at most 2k2^k2k steps. The natural recurrence is

Rk(c,d)=∃m:Rk−1(c,m)∧Rk−1(m,d)R_k(c,d)=\exists m: R_{k-1}(c,m)\land R_{k-1}(m,d) Rk​(c,d)=∃m:Rk−1​(c,m)∧Rk−1​(m,d)

Expanding both recursive calls would double the formula size at every level. Quantifiers allow the two checks to share one recursive copy

Let bbb be one Boolean variable and let u,v,mu,v,mu,v,m be configuration bit vectors. Define

Rk(c,d)=∃m ∀b ∃u,v: [((¬b∧u=c∧v=m)∨(b∧u=m∧v=d))∧Rk−1(u,v)]\begin{aligned}R_k(c,d)=\exists m\ \forall b\ \exists u,v:\\bigl[&((\neg b\land u=c\land v=m)\\&\lor(b\land u=m\land v=d))\land R_{k-1}(u,v)\bigr]\end{aligned}Rk​(c,d)=∃m ∀b ∃u,v: [​((¬b∧u=c∧v=m)∨(b∧u=m∧v=d))∧Rk−1​(u,v)]​

All bound variables introduced at different recursion levels are fresh

For b=0b=0b=0, the recursive call must check the first half; for b=1b=1b=1, it must check the second. The midpoint mmm is chosen before bbb, so both checks use the same midpoint

The base case R0R_0R0​ tests equality or one legal transition. Each level adds O(s)O(s)O(s) symbols, and k=O(s)k=O(s)k=O(s) levels cover every possible simple configuration path. The resulting formula has polynomial size

Arrange the simulated decider to have a unique canonical accepting configuration. Connecting its start configuration to that accepting configuration gives a polynomial-time reduction to TQBF

TQBF is PSPACE-complete under polynomial-time many-one reductions

Savitch’s Theorem

The midpoint recurrence is also an algorithm. Instead of guessing a midpoint, deterministically enumerate all possible midpoint configurations

For space-constructible s(n)≥log⁡ns(n)\ge\log ns(n)≥logn,

NSPACE⁡(s(n))⊆SPACE⁡(s(n)2)\operatorname{NSPACE}(s(n))\subseteq\operatorname{SPACE}(s(n)^2)NSPACE(s(n))⊆SPACE(s(n)2)

To test a path of length at most 2k2^k2k, enumerate mmm and recursively check the two halves. Accept if some midpoint makes both checks succeed

Each stack frame holds a constant number of configurations and counters, requiring O(s(n))O(s(n))O(s(n)) bits. The recursion depth is

k=O(log⁡N)=O(s(n))k=O(\log N)=O(s(n)) k=O(logN)=O(s(n))

Thus the total space is O(s(n)2)O(s(n)^2)O(s(n)2). Recomputing subproblems may take substantial time, but no exponential table of visited configurations is retained

The polynomial-space consequence is

NPSPACE=PSPACE\mathrm{NPSPACE}=\mathrm{PSPACE} NPSPACE=PSPACE

This also justifies the oracle equality from Lecture 8: with a TQBF oracle, deterministic and nondeterministic polynomial-time machines have equal power

Games and Alternating Choices

A quantified formula describes a game. The existential player chooses values for existential variables, the universal player chooses values for universal variables, and moves follow the quantifier order

The existential player wins when the final Boolean formula is true. A winning strategy may depend on earlier moves, matching the dependencies allowed by the quantifiers

Deciding the winner is therefore PSPACE-complete. A depth-first minimax traversal uses polynomial space even when its game tree has exponentially many leaves

Generalized Geography

In directed vertex geography, a token starts at a specified vertex. Players alternately move it along an outgoing edge to a vertex not visited earlier; a player with no legal move loses

A play uses at most ∣V∣|V|∣V∣ vertices. Storing the visited set and a depth-first game-search stack uses polynomial space

The problem is PSPACE-hard through a reduction from the quantified-formula game. Variable gadgets encode choices and their move order; a final clause-selection phase lets one player challenge satisfaction and the other exhibit a true literal

The gadget construction must preserve whose turn it is at each interface. Merely having an exponentially large game tree does not establish PSPACE-hardness

L, NL and Small Workspace

L=SPACE⁡(log⁡n)NL=NSPACE⁡(log⁡n)\mathrm L=\operatorname{SPACE}(\log n)\qquad\mathrm{NL}=\operatorname{NSPACE}(\log n)L=SPACE(logn)NL=NSPACE(logn)

A constant number of input positions and counters fit in logarithmic space. For example, palindrome testing can compare symmetric input positions using two counters and a repeatedly scanned read-only input

Directed reachability, PATH, belongs to NL. Store the current vertex, guess a next vertex, verify the edge, and count at most ∣V∣−1|V|-1∣V∣−1 moves. If a path exists, a simple path of that length exists

A logarithmic-space machine has only polynomially many configurations. Deterministic graph search on its configuration graph therefore shows

L⊆NL⊆PNL⊆SPACE⁡(log⁡2n)\mathrm L\subseteq\mathrm{NL}\subseteq\mathrm P \qquad \mathrm{NL}\subseteq\operatorname{SPACE}(\log^2 n) L⊆NL⊆PNL⊆SPACE(log2n)

The second containment is Savitch’s theorem

Log-Space Reductions and NL-Completeness

A log-space transducer has a read-only input, O(log⁡n)O(\log n)O(logn) work cells, and a write-only output. The output is not counted as workspace

Write A≤LBA\le_L BA≤L​B when such a transducer computes a many-one reduction. Polynomial-time reductions would be too powerful here: every language in P\mathrm PP can be decided during the reduction itself

Composing Small-Space Computations

If the reduction output is polynomially long, it cannot all be stored on a logarithmic work tape. Instead, keep the simulated input-head position of the target algorithm and recompute the required output symbol whenever it is needed

Restarting the transducer costs time, but uses only logarithmic space. This proves closure under composition and the implication A≤LBA\le_L BA≤L​B, B∈L⇒A∈LB\in\mathrm L\Rightarrow A\in\mathrm LB∈L⇒A∈L

PATH Is NL-Complete

For any NL machine, map an input to its configuration graph with distinguished start and accepting vertices. An accepting computation exists exactly when those vertices are connected by a directed path

Two configuration descriptions occupy only O(log⁡n)O(\log n)O(logn) bits. A transducer can enumerate configuration pairs, test whether a legal transition joins them, and output graph edges one at a time

Thus every NL language log-space reduces to PATH

Complementation and Hierarchy

The Immerman-Szelepcsényi theorem states

NL=coNL\mathrm{NL}=\mathrm{coNL}NL=coNL

The proof certifies the number of reachable vertices by inductive counting. It does not complement a nondeterministic machine simply by swapping its accepting and rejecting states. The counting argument is developed at the beginning of Lecture A

For space-constructible s1,s2≥log⁡ns_1,s_2\ge\log ns1​,s2​≥logn with s1(n)=o(s2(n))s_1(n)=o(s_2(n))s1​(n)=o(s2​(n)), the deterministic space hierarchy gives

SPACE⁡(s1(n))⊊SPACE⁡(s2(n))\operatorname{SPACE}(s_1(n)) \subsetneq\operatorname{SPACE}(s_2(n)) SPACE(s1​(n))⊊SPACE(s2​(n))

Combining this with Savitch’s bound shows NL⊊PSPACE\mathrm{NL}\subsetneq\mathrm{PSPACE}NL⊊PSPACE. The individual equalities L=NL\mathrm L=\mathrm{NL}L=NL, NL=P\mathrm{NL}=\mathrm PNL=P, and P=NP\mathrm P=\mathrm{NP}P=NP are not settled by these hierarchy arguments
