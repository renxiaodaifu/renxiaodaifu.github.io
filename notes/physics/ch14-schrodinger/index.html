Chapter E - 薛定谔方程

薛定谔方程

薛定谔方程不能由其它的基本原理推导得到，是量子力学的一个基本的假设，其正确性也只能靠实验来检验，其是一个线性偏微分方程，形式为：

iℏ∂Ψ∂t=[−ℏ22m∇2+U]Ψi\hbar\frac{\partial\Psi}{\partial t} = \left[-\frac{\hbar^2}{2m}\nabla^2 + U\right]\Psiiℏ∂t∂Ψ​=[−2mℏ2​∇2+U]Ψ

其中，U(r⃗,t)U(\vec{r}, t)U(r,t) 是例子在外力场中的势能函数

由线性性可知，薛定谔方程符合态叠加原理

哈密顿量

我们定义哈密顿算符:

H^=−ℏ22m∇2+U\hat{H} = -\frac{\hbar^2}{2m}\nabla^2 + U H^=−2mℏ2​∇2+U

则方程可以简化为：

iℏ∂Ψ∂t=H^Ψi\hbar\frac{\partial\Psi}{\partial t} = \hat{H}\Psi iℏ∂t∂Ψ​=H^Ψ

哈密顿量决定了微观粒子波函数随时间的演化，即决定了粒子的运动状态，其中的势函数 UUU 一般情况下可以表示外界对粒子的所有作用

当 UUU 与时间无关时，容易看出薛定谔方程可以通过分离变量求解，此时 H^\hat{H}H^ 被称为能量算符

之后的讨论都假设 UUU 与时间无关

定态薛定谔方程

当 UUU 与时间无关的时候，整个方程称为定态薛定谔方程，也被称为能量本征方程

假设：

Ψ(r⃗,t)=Φ(r⃗)⋅T(t)\Psi(\vec{r}, t) = \Phi(\vec{r})\cdot T(t) Ψ(r,t)=Φ(r)⋅T(t)

则代入薛定谔方程可得：

iℏΦ⋅dTdt=(H^Φ)⋅Ti\hbar\Phi\cdot\frac{\mathrm{d}T}{\mathrm{d}t} = \left(\hat{H}\Phi\right)\cdot T iℏΦ⋅dtdT​=(H^Φ)⋅T

化简得到：

iℏ⋅dTTdt=H^ΦΦ:=Ei\hbar\cdot\frac{\mathrm{d}T}{T\mathrm{d}t} = \frac{\hat{H}\Phi}{\Phi} := E iℏ⋅TdtdT​=ΦH^Φ​:=E

假设其中 EEE 是常数，则得到两个方程：

iℏ⋅dTdt=ETH^Φ=EΦ\begin{align} i\hbar\cdot\frac{\mathrm{d}T}{\mathrm{d}t} &= ET \\[1em] \hat{H}\Phi &= E\Phi \end{align} iℏ⋅dtdT​H^Φ​=ET=EΦ​​

方程 (1) 很容易解出来：

T(t)=Ce−iℏEt,C∈CT(t) = Ce^{-\frac{i}{\hbar}Et},\quad C \in \mathbb{C} T(t)=Ce−ℏi​Et,C∈C

这被称为振动因子

而方程 (2) 整个方程是与时间无关的，被称为定态薛定谔方程，也被称为能量本征方程

EEE 取任何值的时候方程都有解，但只有某些值对应的解有物理意义（对应波函数的条件），这些取值被称为能量本征值，与之对应的解 ΦE\Phi_EΦE​ 被称为本征波函数；其物理含义是：若粒子处于 ΦE\Phi_EΦE​ 状态，则能量为 EEE

当 EEE 被固定下来之后，实际上得到的是薛定谔方程的一个特解（这也是为什么方程 (2) 被称为定态）：

ΨE(r⃗,t)=ΦE(r⃗)e−iℏEt\Psi_E(\vec{r}, t) = \Phi_E(\vec{r})e^{-\frac{i}{\hbar}Et} ΨE​(r,t)=ΦE​(r)e−ℏi​Et

为讨论方便，我们假设 EEE 取到的是分立的值，因此特解的数量可数，根据态叠加原理，薛定谔方程的通解可以表示为：

Ψ=∑nCnΨn=∑nCnΦne−iℏEt,∀n,  Cn∈C\Psi = \sum\limits_{n}C_n\Psi_n = \sum\limits_{n}C_n\Phi_ne^{-\frac{i}{\hbar}}Et, \quad \forall n,\,\,C_n \in \mathbb{C} Ψ=n∑​Cn​Ψn​=n∑​Cn​Φn​e−ℏi​Et,∀n,Cn​∈C

  • 散射：给定 EEE 和势垒 U(x)U(x)U(x)，计算穿透势垒概率

考虑如下的一维势垒：

证明思路

首先解定态薛定谔方程，得到：

Φ(x)={Ae−ik1x+Beik1xx≤0Ce−k2x+Dek2x0<x≤aEe−ik1x+Feik1xx>a\Phi(x) = \begin{cases} Ae^{-ik_1x} + Be^{ik_1 x} & x \leq 0 \\[1em] Ce^{-k_2x} + De^{k_2 x} & 0 < x \leq a \\[1em] Ee^{-ik_1x} + Fe^{ik_1 x} & x > a\end{cases}Φ(x)=⎩⎨⎧​Ae−ik1​x+Beik1​xCe−k2​x+Dek2​xEe−ik1​x+Feik1​x​x≤00<x≤ax>a​

  • 根据物理含义，xxx 符号为负的项代表的是向左传播的概率波，而在 x>ax > ax>a 内波只能向右传播（无法反射），因此 E=0E = 0E=0
  • 利用 x=0x = 0x=0 和 x=ax = ax=a 处波函数及其导数的连续性得到四个方程
  • 假设入射波的振幅为单位 1，即 A=1A = 1A=1，这一步是为了避免方程数量小于未知数个数

即可解出所有系数
