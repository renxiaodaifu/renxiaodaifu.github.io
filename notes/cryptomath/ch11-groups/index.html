密码学数学基础 - 群、同态与循环群

密码学数学基础 笔记 11：从群公理出发，讨论群范畴与同态，再用阶、子群和循环群回答“一个元素能生成多少结构”，最后回到 RSA 与离散对数的参数选择

群、同态与循环群

上一篇把商集、积与余积放进了范畴的语言，但那里的对象还只是集合。整数按模 nnn 取商之后自带加法与乘法，这类“集合加运算”的结构需要单独刻画。现在去掉交换律，只保留结合律、单位元与逆元，得到群

这一篇围绕一个问题展开：一个元素能生成多少结构？答案由同态

ϵg:Z→G,n↦gn\epsilon_g:\mathbb Z\to G,\qquad n\mapsto g^n ϵg​:Z→G,n↦gn

给出，它的像是循环群，核记录了 ggg 的周期。顺着这条线索，前面讨论过的模运算、原根与离散对数都能在同一个框架中重新表述

从合成律到群

集合 SSS 上的一个合成律，是一个映射

m:S×S→S,(x,y)↦xym:S\times S\to S,\qquad (x,y)\mapsto xy m:S×S→S,(x,y)↦xy

它把两个元素重新送回集合内部。在此基础上逐条增加要求，就得到一串越来越强的结构：

半群 合成律满足结合律
幺半群 半群，且存在单位元
群 幺半群，且每个元素可逆

于是群 (G,⋅)(G,\cdot)(G,⋅) 就是带有二元运算的集合，满足

∀g,h,k∈G:(gh)k=g(hk)\forall g,h,k\in G:\quad (gh)k=g(hk) ∀g,h,k∈G:(gh)k=g(hk)

∃eG∈G ∀g∈G:geG=g=eGg\exists e_G\in G\ \forall g\in G:\quad ge_G=g=e_Gg ∃eG​∈G ∀g∈G:geG​=g=eG​g

∀g∈G ∃h∈G:gh=hg=eG\forall g\in G\ \exists h\in G:\quad gh=hg=e_G ∀g∈G ∃h∈G:gh=hg=eG​

三条公理给出三种能力：重新加括号、什么都不做、把元素撤销。量化顺序也有实际含义：单位元 eee 对全体 ggg 只有同一个，而逆元是对每个 ggg 分别存在一个

记号上，乘法写法用 111、g−1g^{-1}g−1、gng^ngn，加法写法用 000、−g-g−g、ngngng。加法记号通常留给交换群，但这些符号并不表示数：元素可能是几何变换，运算可能是函数复合。同一个集合还可以承载不同的群结构，例如 {0,1}n\{0,1\}^n{0,1}n 上按位异或与模 2n2^n2n 加法给出两个不同的群

群范畴与同态

群之间的“保持结构的映射”是群同态：函数 φ:G→H\varphi:G\to Hφ:G→H 满足

φ(ab)=φ(a)φ(b)\boxed{\varphi(ab)=\varphi(a)\varphi(b)} φ(ab)=φ(a)φ(b)​

用它可以把乘法图与映射图拼在一起。记 mG:G×G→Gm_G:G\times G\to GmG​:G×G→G 为 GGG 的乘法，则 φ\varphiφ 诱导

(φ×φ):G×G→H×H,(a,b)↦(φ(a),φ(b))(\varphi\times\varphi):G\times G\to H\times H,\qquad (a,b)\mapsto(\varphi(a),\varphi(b)) (φ×φ):G×G→H×H,(a,b)↦(φ(a),φ(b))

而同态条件等价于说下图交换

G×G→mGGφ×φ↓↓φH×H→mHH\begin{array}{ccc} G\times G&\xrightarrow{m_G}&G\\ {\scriptstyle \varphi\times\varphi}\downarrow&&\downarrow{\scriptstyle\varphi}\\ H\times H&\xrightarrow{m_H}&H \end{array} G×Gφ×φ↓H×H​mG​​mH​​​G↓φH​

也就是“先乘再映射”与“先映射再乘”结果相同。以群为对象、以群同态为态射，就得到范畴 Grp\mathsf{Grp}Grp；恒等映射是同态，同态的复合仍是同态，这两点保证 Grp\mathsf{Grp}Grp 确实是范畴

平凡群是一个零对象

单点集 {∗}\{*\}{∗} 配上 ∗⋅∗=∗*\cdot*=*∗⋅∗=∗ 是最简单的群，记为 111 或 000

它在 Grp\mathsf{Grp}Grp 中同时是终对象与始对象：

  • 作为终对象，任意群 GGG 到 {∗}\{*\}{∗} 的映射只能是常值映射，而它保持乘法
  • 作为始对象，{∗}→G\{*\}\to G{∗}→G 的同态必须把 eee 送到 eGe_GeG​，因此也只有一条

{∗} 是 Grp 的零对象\boxed{\{*\}\text{ 是 }\mathsf{Grp}\text{ 的零对象}} {∗} 是 Grp 的零对象​

这与 Set\mathsf{Set}Set 形成对照：那里空集是始对象，非空集合才是终对象，没有零对象

积、余积与同态集合

给定群 G,HG,HG,H，笛卡尔积按分量定义运算

(g1,h1)(g2,h2)=(g1g2, h1h2)(g_1,h_1)(g_2,h_2)=(g_1g_2,\ h_1h_2) (g1​,h1​)(g2​,h2​)=(g1​g2​, h1​h2​)

得到的群称为直积 G×HG\times HG×H，单位元是 (eG,eH)(e_G,e_H)(eG​,eH​)，逆元是 (g−1,h−1)(g^{-1},h^{-1})(g−1,h−1)，公理逐坐标验证。两个投影

πG:G×H→G,πH:G×H→H\pi_G:G\times H\to G,\qquad \pi_H:G\times H\to H πG​:G×H→G,πH​:G×H→H

都是满同态。它们满足积的泛性质：对任意群 AAA 与同态 φG:A→G\varphi_G:A\to GφG​:A→G、φH:A→H\varphi_H:A\to HφH​:A→H，存在唯一的同态

φG×φH:A→G×H,a↦(φG(a),φH(a))\varphi_G\times\varphi_H:A\to G\times H,\qquad a\mapsto(\varphi_G(a),\varphi_H(a)) φG​×φH​:A→G×H,a↦(φG​(a),φH​(a))

使两个投影都交换。这里存在性与唯一性可以直接从 Set\mathsf{Set}Set 借来，只需再检查它是同态，而这由分量运算逐项得出。于是

Hom⁡(A,G×H)≅Hom⁡(A,G)×Hom⁡(A,H)\boxed{\operatorname{Hom}(A,G\times H)\cong\operatorname{Hom}(A,G)\times\operatorname{Hom}(A,H)} Hom(A,G×H)≅Hom(A,G)×Hom(A,H)​

即“给出一条到积的同态，等价于分别给出到两个因子的同态”

为什么直积不是余积

在阿贝尔群范畴 Ab\mathsf{Ab}Ab 中，有限族的情形下直积同时是直和与余积，三种角色重合。在 Grp\mathsf{Grp}Grp 中这个等式就断开了

若试图把 G×HG\times HG×H 做成余积，自然的选择是

iG(g)=(g,e),iH(h)=(e,h)i_G(g)=(g,e),\qquad i_H(h)=(e,h) iG​(g)=(g,e),iH​(h)=(e,h)

但这两类元素在 G×HG\times HG×H 中总是交换的：

(g,e)(e,h)=(g,h)=(e,h)(g,e)(g,e)(e,h)=(g,h)=(e,h)(g,e) (g,e)(e,h)=(g,h)=(e,h)(g,e)

于是一条满足 u∘iG=fGu\circ i_G=f_Gu∘iG​=fG​、u∘iH=fHu\circ i_H=f_Hu∘iH​=fH​ 的同态 uuu，必然迫使 fG(g)f_G(g)fG​(g) 与 fH(h)f_H(h)fH​(h) 在目标群中交换。可余积必须允许任意的同态 fG,fHf_G,f_HfG​,fH​ 进入目标，不能额外强加关系。问题就出在关键一步用了交换性，而这条公理已经被去掉

群范畴中真正的余积是自由积 G∗HG*HG∗H，它的元素是两边的字交错排列后得到的等价类，比直积复杂得多。一个直观对比是：C2×C2C_2\times C_2C2​×C2​ 只有 444 个元素，而 C2∗C2C_2*C_2C2​∗C2​ 是无限群

同构：同一个群的不同写法

同态 φ:G→H\varphi:G\to Hφ:G→H 称为同构，如果存在同态 ψ:H→G\psi:H\to Gψ:H→G 使 ψ∘φ=id⁡G\psi\circ\varphi=\operatorname{id}_Gψ∘φ=idG​、φ∘ψ=id⁡H\varphi\circ\psi=\operatorname{id}_Hφ∘ψ=idH​。在 Grp\mathsf{Grp}Grp 中这与“双射同态”等价：双射的逆作为集合函数存在，只需验证它也保持乘法，而这只要在 φ(ab)=φ(a)φ(b)\varphi(ab)=\varphi(a)\varphi(b)φ(ab)=φ(a)φ(b) 两边作用 φ−1\varphi^{-1}φ−1 即可

存在同构时记 G≅HG\cong HG≅H。同构是等价关系：恒等映射给出自反性，逆映射给出对称性，复合给出传递性。群论中的性质在同构下保持不变，包括阶、元素阶的分布、子群结构与是否交换

一个与密码学直接相关的例子来自原根。设 ggg 是模素数 ppp 的原根，则

子群、核与生成

子集 H⊆GH\subseteq GH⊆G 称为子群，如果它在诱导运算下本身是群，等价地，包含映射 H↪GH\hookrightarrow GH↪G 是同态。这意味着 HHH 中的运算必须与 GGG 中一致，{±1}\{\pm1\}{±1} 在乘法下是群，却不是 (Z,+)(\mathbb Z,+)(Z,+) 的子群

验证子群不必逐条检查公理。非空子集 H⊆GH\subseteq GH⊆G 是子群，当且仅当

g,h∈H ⟹ gh−1∈H\boxed{g,h\in H\ \Longrightarrow\ gh^{-1}\in H} g,h∈H ⟹ gh−1∈H​

因为取 g=hg=hg=h 得到 e∈He\in He∈H，再取 g=eg=eg=e 得到 h−1∈Hh^{-1}\in Hh−1∈H，最后把 hhh 换成 h−1h^{-1}h−1 就得到 gh∈Hgh\in Hgh∈H。结合律由 GGG 继承，非空条件不能去掉

若 GGG 是阿贝尔群，条件可以写成减法形式

S≠∅,x,y∈S ⟹ x−y∈SS\neq\varnothing,\quad x,y\in S\ \Longrightarrow\ x-y\in S S=∅,x,y∈S ⟹ x−y∈S

这正是第 3 篇中的模数：非空且对加减封闭的整数集合。所以“模数”与“Z\mathbb ZZ 的子群”是同一件事，它也正好是 Z\mathbb ZZ 的理想

几个常用的构造：

  • 任意多个子群的交仍是子群，因为一步判别可以穿过交集
  • 并通常不行：2Z∪3Z2\mathbb Z\cup3\mathbb Z2Z∪3Z 含 222 与 333，却不含 2+3=52+3=52+3=5；实际上 H∪KH\cup KH∪K 是子群当且仅当其中一个包含另一个
  • 同态的像 φ(H)\varphi(H)φ(H) 与 im⁡φ\operatorname{im}\varphiimφ 是陪域的子群
  • 子群的原像 φ−1(H′)\varphi^{-1}(H')φ−1(H′) 是定义域的子群

为什么 DLP 参数要取素数阶子群

循环群的分类说明，同阶的循环群在抽象层面完全一样。但求解离散对数的难度，取决于群的阶的分解

同构不等于计算等价

循环群 G=⟨g⟩G=\langle g\rangleG=⟨g⟩ 的阶为 NNN 时，抽象同构

Z/NZ⟶G,[x]N↦gx\mathbb Z/N\mathbb Z\longrightarrow G,\qquad [x]_N\mapsto g^x Z/NZ⟶G,[x]N​↦gx

总是存在。离散对数就是计算它的逆映射。可是如果在加法模型中工作，同样的任务变成解线性同余

ax≡b(modN)ax\equiv b\pmod N ax≡b(modN)

它要么在 gcd⁡(a,N)∤b\gcd(a,N)\nmid bgcd(a,N)∤b 时无解，要么由扩展欧几里得算法在多项式时间内解出。两个群结构相同，计算难度却不在同一个量级

因此，群的分类只回答“结构是什么”，不回答“表示下难不难算”。密码学所依赖的，正是同一个同构在两个方向上代价的不对称；而这篇中的公理、同态、核、阶与子群，提供了描述这种不对称所需的全部语言
